# 学習計画ビューア（index.html）このreadmeは内容を可能なら増やさない

その日にやる範囲を縦に並べて表示する、1ファイル完結のHTML。ブラウザで `index.html` を開くだけで動く（サーバー・外部ライブラリ不要）。

## 現在の計画（全体表示の基準日 2026-10-17）

| 科目 | 教材 | 総量・残量 | 期間・ペース |
|---|---|---:|---|
| 数学 | 数IA（610p）→ 数IIB（931p）→ 数III（719p）の順 | 2260p | 60日、約37〜38p/日。終了予定 12/13 |
| 英文法 | 英文法 | 全219pのうち16p完了（残り203p） | 残り25日、約8〜9p/日。終了予定 11/10 |
| 最短物理 | 最短物理 | 全244ページのうち22ページ分を開始時点で完了扱い（残り222p） | 15日、約14〜15p/日。開始 10/17、終了予定 10/31 |
| 英文英単語Z | 英文英単語Z＋付随する英単語 | 70個 | 1日3個、24日。終了予定 11/7 |

終了日は開始日を1日目として数えた予定日です。実際の表示範囲は `index.html` の設定に従います。

- 数学は1冊ずつ順番に進める（IAが終わったらIIB、次にIII）。日をまたいで冊が切り替わる日は、2行に分かれて表示される。
- 英文法は1〜16ページを完了扱いにし、残り203ページを25日間で進める（1日あたり約8〜9ページ）。
- 物理は `skip:22` により、開始時点で22ページ分を完了扱いにして残りを15日で進める。

## 機能

- 日付ごとに、各科目の範囲を縦に表示（例：`数IA 1〜37ページ`）。
- 開くと今日の日付を表示。日付が変わると自動で更新（「今日」を見ているときのみ追従。30秒ごと＋タブ復帰時にチェック）。
- 左右の矢印（枠なし）で1日進む／戻る。キーボードの ← → も可。他の日を見ているときは「今日に戻る」が出る。
- 左上のカレンダーボタンで月カレンダーを開き、日付を押すとその日の予定を表示。計画期間内の日は薄く色が付く。
- 右上の「変更履歴」ボタンで、画面いっぱいの履歴画面を開き、日付・内容を検索できる。閉じると元の画面位置に戻る。
- 完了した科目は、その日以降「一周済み: ○○」と表示。
- ダークモード対応（OS設定に追従）。

## 共有メモの有効化（Cloudflare Pages + D1）

共有メモは Cloudflare Pages Functions と D1 データベースで保存します。フロントエンドにAPIキーを置く必要はありません。

1. Cloudflare の **Workers & Pages** で、この GitHub リポジトリを Pages プロジェクトとしてデプロイします。
2. **Settings → Bindings** で D1 database binding を追加し、Variable name を `DB`、データベースを `kanshi-notes` にして保存します。
3. Cloudflare の **D1 → kanshi-notes → Console** を開き、次のSQLを実行してテーブルを作成します（リポジトリ内の `migrations/0001_create_kanshi_notes.sql` と同じ内容です）。

```sql
CREATE TABLE IF NOT EXISTS kanshi_notes (
  note_date TEXT NOT NULL,
  task_name TEXT NOT NULL,
  content TEXT NOT NULL CHECK (length(content) <= 500),
  updated_at TEXT NOT NULL DEFAULT (datetime('now')),
  PRIMARY KEY (note_date, task_name)
);
```

4. GitHub に反映された `functions/api/notes.js` と `index.html` が自動デプロイされるのを待ち、公開サイトを開いてメモを保存します。
5. 別のブラウザや端末で同じ日付・科目を開き、メモが共有されることを確認します。

共有メモは約30秒ごとに再読み込みされます。以前の `localStorage` にあるメモは自動移行されず、その端末に残ります。

**公開範囲に注意：** このサイトを開ける人は誰でもメモを閲覧・追加・編集・削除できます。秘密情報や個人情報は書かないでください。APIは入力内容を検証しますが、ログインや編集者制限はありません。

## 編集方法

編集するのは `index.html` 内の `<script>` 冒頭の **設定ブロック** だけ（`/* ===== 設定 ===== */` で囲まれた部分）。

```js
const TIMELINE_START = "2026-10-17"; // 全体の日数表示の基準日

const TASKS = [
  { name:"数学", color:"--math", days:60, start:"2026-10-15",
    segments:[
      { label:"数IA",  total:610, unit:"ページ" },
      { label:"数IIB", total:931, unit:"ページ" },
      { label:"数III", total:719, unit:"ページ" } ] },
  { name:"英文法", color:"--eng", days:25, start:"2026-10-17", skip:16,
    segments:[ { label:"英文法", total:219, unit:"ページ" } ] },
  { name:"最短物理", color:"--phy", days:15, start:"2026-10-17", skip:22,
    segments:[ { label:"最短物理", total:244, unit:"ページ" } ] },
  { name:"英文英単語Z", color:"--sent", perDay:3, start:"2026-10-15",
    segments:[ { label:"英文英単語Z", total:70, unit:"", extra:"＋ 付随する英単語" } ] }
];
```

### TASKS の各項目

| キー | 意味 |
|---|---|
| `name` | 科目名（カードの見出し） |
| `color` | 色。`--math` `--eng` `--phy` `--sent` のどれか（CSSの `:root` で定義。増やすならそこに追加） |
| `days` | 全体を何日で一周するか。総量を均等割りする |
| `perDay` | 1日の固定量。`days` の代わりに使う。日数は `ceil(総量÷perDay)` で自動計算、余りは最終日 |
| `start` | そのタスクの開始日（必須） |
| `skip` | 開始時点で完了扱いにする量 |
| `segments` | 順番にこなす教材のリスト。`label`=表示名、`total`=量、`unit`=単位（「ページ」など。不要なら `""`）、`extra`=範囲の後ろに付ける補足（任意） |

`days` と `perDay` はどちらか一方だけ書く。

### 変更履歴の追加方法

画面右上の「変更履歴」を押すと、画面いっぱいの履歴専用画面が開きます。最新の日付が一番上で、履歴一覧だけをスクロールできます。画面上部の検索窓では、日付または変更内容の一部を入力して一致する履歴を絞り込めます。×ボタンで閉じると、メイン画面は開く前のスクロール位置に戻ります。履歴は `index.html` の `CHANGELOG` に記録し、日付の新しい順に自動で並びます。

```js
const CHANGELOG = [
  { date:"2026-10-20", text:"変更履歴を追加。" },
  { date:"2026-10-17", text:"英文法の1〜16ページを完了扱いに設定。" },
  { date:"2026-10-17", text:"学習計画を今日開始に変更。英文法を25日間に調整。" }
];
```

- `date`：変更日（`YYYY-MM-DD` 形式）
- `text`：人が読んですぐ分かる短い説明。変更した理由や細かい実装より、「何が変わったか」を1文で書く。
- 履歴は自動記録ではありません。変更を加えたときに、手動で追記します。
- 日付は `YYYY-MM-DD` 形式で入力してください。日付が同じ履歴は、同じ日付のグループ内で元の記載順になります。
- 検索は日付と変更内容の両方が対象です。検索欄を空にすると全履歴に戻ります。

### よくある変更

- **科目の開始日を変える** → その科目の `start` を書き換える。全体の日数表示の基準日は `TIMELINE_START` で設定する。
- **日数・ペースを変える** → `days` / `perDay` を変更。
- **ページ数を変える** → 該当 `segments` の `total` を変更。
- **科目を追加** → `TASKS` に1オブジェクト追加（色が必要なら `:root` と `@media (prefers-color-scheme:dark)` の両方に `--xxx` を追加）。
- **見た目** → `<style>` 内のCSS。色は先頭の `:root` の変数で一括管理。

## 仕組み（コードの読み方）

- `dayIndex(date)`：`TIMELINE_START` からの日数（0始まり）。各科目の表示範囲は、それぞれの `start` を基準に計算する。
- `span(task, d)`：d日目に担当する範囲を、通し番号の半開区間 `[s, e)` で返す。
- `linesOf(task, d)`：通し番号の範囲を `segments` ごとに分割し、各教材内のページ番号（1始まり）に直す。
- `render()`：表示中の日付 `view` から画面を描画。`today` は実際の今日、`view` は表示中の日。
- 状態は `today` / `view` / `calMonth` の3つだけ。保存はしない（開くたびに今日から）。
